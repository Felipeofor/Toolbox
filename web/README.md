# Toolbox Web

Frontend React 18 + React Bootstrap (Webpack 5) que consume el API local de Toolbox.

## Requisitos

- Node 16.x (`nvm use` lee `.nvmrc`)
- npm
- API de Toolbox corriendo en `http://localhost:3000`

## Scripts

- `npm start` — webpack-dev-server en puerto 8080.
- `npm run build` — build de producción en `dist/`.
- `npm test` — Jest (opcional).

Ver `/README.md` raíz para arquitectura completa.
